# Retirement Nest Egg Savings Planner
Project your retirement savings balance using compound interest with a year-by-year breakdown and decade chart.
## Features
- Inputs for current age, retirement age, current savings, annual contribution, and expected return
- Projected balance at retirement with 4% rule annual and monthly withdrawal estimates
- Collapsible year-by-year table showing balance, interest earned, and total contributed
- Decade-by-decade bar chart with hover tooltips
## Tech
Static SPA · Tailwind CDN · localStorage
